Create one completed copy per mandatory task. Do not mark PASS until the test is actually run.

|---|---|

| Exact test input/request | |
| Expected behaviour | |
| Actual frontend output | |
| Actual API response/status | |
| Backend log / trace | |
| Database row / audit evidence | |
| Screenshot filename | |
| Result | PASS / FAIL / BLOCKED |
| Explanation and follow-up fix | |

## Suggested evidence folder

Save evidence under `evidence/` using names such as `task-01-incomplete-input.png`, `task-01-api.txt`, and `task-01-db.txt`. Do not put API keys, tokens, passwords or personal data in evidence.
